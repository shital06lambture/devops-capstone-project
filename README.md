# DevOps Capstone

## Project Description

This project is part of the IBM DevOps and Software Engineering Capstone. It demonstrates DevOps practices by developing, testing, containerizing, and deploying a Customer Accounts REST API microservice.

## Build Status

[![Build Status](https://github.com/shital06lambture/devops-capstone-project/actions/workflows/ci-build.yaml/badge.svg?branch=main)](https://github.com/shital06lambture/devops-capstone-project/actions/workflows/ci-build.yaml)

## Features

- Create a new customer account.
- Read account details.
- List all customer accounts.
- Update an existing account.
- Delete an account.
- Run automated tests and code quality checks.
- Containerize the application using Docker.
- Support deployment using container and CI/CD tools.

## Technologies Used

- Python and Flask
- REST API
- PostgreSQL
- Git and GitHub
- GitHub Actions
- Docker
- Kubernetes
- Automated testing with Nose and code quality checks with Flake8

## Project Objective

The objective is to apply DevOps principles such as continuous integration, automated testing, containerization, and deployment automation to a Customer Accounts REST API microservice.
